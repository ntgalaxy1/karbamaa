# 📱 راهنمای جامع تنظیم نام بسته (Package Name)، کلید امضای دیجیتال (Keystore) و انتشار نسخه ۱۰.۰.۰.۱ کارباما در گیت‌هاب

این راهنما گام‌به‌گام به شما آموزش می‌دهد که چگونه:
1. **نام بسته (Package Name)** را به صورت دلخواه تنظیم کنید.
2. **کلید امضای دیجیتال معتبر (Keystore)** بسازید و اثر انگشت **SHA-256** را استخراج نمایید.
3. با اتصال فایل `assetlinks.json` نوار آدرس مرورگر را به طور کامل حذف کرده و برنامه را به یک اپلیکیشن **تمام‌صفحه و کاملاً بومی (Native)** تبدیل کنید.
4. پروژه را در **گیت‌هاب (GitHub)** قرار داده و خروجی نسخه **۱۰.۰.۰.۱** را به صورت خودکار با GitHub Actions منتشر کنید.
5. **فایل APK را مستقیماً از گیت‌هاب دانلود کنید.**

---

## ۱. نام بسته (Package Name) چیست و چگونه آن را تنظیم کنیم؟

### نام بسته چیست؟
نام بسته (مانند `app.karbama.twa` یا `com.karbama.app`) شناسه منحصر‌به‌فرد اپلیکیشن شما در سیستم‌عامل اندروید و فروشگاه‌های **Google Play**، **کافه‌بازار** و **مایکت** است. این نام نباید با هیچ اپلیکیشن دیگری در دنیا تکرار شود و معمولاً با فرمت معکوس دامنه اینترنتی نوشته می‌شود.

### نام بسته فعلی پروژه:
نام بسته پیش‌فرض پروژه کارباما:
```text
app.karbama.twa
```

### چگونه نام بسته را در پروژه تغییر دهیم؟
اگر مایلید نام بسته را به نام دلخواه خود (مثلاً `com.mycompany.karbama`) تغییر دهید، تنها کافی است ۳ فایل زیر را با نام جدید به‌روزرسانی کنید:

1. **فایل `scripts/generate-apk.py`**:
   پارامتر `package_name` را به نام دلخواه خود تغییر دهید یا هنگام اجرا فلگ زیر را ارسال کنید:
   ```bash
   python3 scripts/generate-apk.py --package-name com.mycompany.karbama --version 10.0.0.1
   ```
2. **فایل `public/.well-known/assetlinks.json`**:
   مقدار `"package_name"` را تغییر دهید:
   ```json
   {
     "relation": ["delegate_permission/common.handle_all_urls"],
     "target": {
       "namespace": "android_app",
       "package_name": "com.mycompany.karbama",
       "sha256_cert_fingerprints": [
         "14:6D:E9:DE:0F:73:98:E8:A6:49:15:32:89:12:34:56:78:90:AB:CD:EF:12:34:56:78:90:AB:CD:EF:12:34:56"
       ]
     }
   }
   ```
3. **فایل `public/manifest.json`**:
   بخش `related_applications` را بررسی نمایید.

## ۲. ساخت کلید امضای دیجیتال اندروید (Keystore / JKS)

سیستم‌عامل اندروید نصب هر برنامه‌ای را منوط به داشتن یک کلید امضای دیجیتال معتبر می‌داند.

### دستور ساخت کلید امضا با ابزار رسمی `keytool`:
ابزار `keytool` به صورت پیش‌فرض در جاوا (JDK) وجود دارد. ترمینال یا CMD را باز کرده و دستور زیر را اجرا کنید:

```bash
keytool -genkey -v -keystore karbama-release.keystore -alias karbama-key -keyalg RSA -keysize 2048 -validity 10000
```

### اطلاعات درخواستی در حین ساخت:
- **Keystore Password (رمز عبور کلید)**: یک رمز قوی انتخاب کنید (مثلاً `Karbama2026@Pass`). **این رمز را حتماً یادداشت کنید.**
- **First and Last Name**: نام و نام خانوادگی شما (مثلاً `Naser Tavakkoli`).
- **Organizational Unit / Organization**: نام موسسه (مثلاً `Karbama Ltd`).
- **City / State / Country Code**: شهر و کد کشور (مثلاً `Istanbul` و `TR` یا `IR`).
- در پایان عبارت `yes` یا `y` را برای تایید وارد کنید.

فایلی با نام **`karbama-release.keystore`** در پوشه شما ایجاد می‌شود.

> ⚠️ **هشدار امنیتی بسیار مهم**: این فایل کلید و رمز آن را در مکانی امن نگه دارید. در صورت گم شدن این فایل، امکان انتشار آپدیت‌های بعدی برای کاربران قبلی در گوگل‌پلی وجود نخواهد داشت.

## ۳. استخراج اثر انگشت SHA-256 و اتصال به دامنه (Digital Asset Links)

یکی از بزرگترین مزیت‌های استاندارد **TWA (Trusted Web Activity)** این است که وقتی دامنه و کلید امضا با یکدیگر پیوند می‌خورند، **نوار آدرس مرورگر کاملاً مخفی شده** و برنامه ۱۰۰٪ شبیه به یک اپلیکیشن Native اجرا می‌شود.

### دستور استخراج SHA-256 از فایل Keystore:
```bash
keytool -list -v -keystore karbama-release.keystore -alias karbama-key
```
رمز عبور را وارد کنید. در خروجی ترمینال، بخشی با عنوان **Certificate fingerprints** خواهید دید:
```text
Certificate fingerprints:
     SHA1: 2B:6F:A1:02:...
     SHA256: 14:6D:E9:DE:0F:73:98:E8:A6:49:15:32:89:12:34:56:78:90:AB:CD:EF:12:34:56:78:90:AB:CD:EF:12:34:56
```

مقدار جلوی **SHA256** را کپی کرده و در فایل زیر قرار دهید:
📁 `public/.well-known/assetlinks.json`

## ۴. تنظیم کلید در مخزن گیت‌هاب (GitHub Secrets)

برای اینکه گیت‌هاب بتواند به صورت خودکار در فضای ابری فایل APK را با کلید شما امضا و منتشر کند:

### گام اول: تبدیل فایل Keystore به متن Base64
در لینوکس، مک یا ترمینال گیت‌بش ویندوز دستور زیر را اجرا کنید:
```bash
base64 -w 0 karbama-release.keystore > keystore_base64.txt
```
(یا در ویندوز پاورشل: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("karbama-release.keystore")) | Out-File keystore_base64.txt`)

### گام دوم: اضافه کردن در گیت‌هاب
1. وارد مخزن پروژه خود در گیت‌هاب شوید (`https://github.com/<نام_کاربری>/<نام_مخزن>`).
2. به تب بالای صفحه به نام **Settings** بروید.
3. در منوی سمت چپ، گزینه **Secrets and variables** و سپس **Actions** را لمس کنید.
4. روی دکمه سبز **New repository secret** بزنید و موارد زیر را تعریف کنید:

| نام Secret | مقدار (Value) |
| :--- | :--- |
| `ANDROID_KEYSTORE_BASE64` | کل محتوای متنی فایل `keystore_base64.txt` |
| `KEYSTORE_PASSWORD` | رمز عبوری که در هنگام ساخت کلید انتخاب کردید |
| `KEY_ALIAS` | نام مستعار کلید (پیش‌فرض: `karbama-key`) |
| `KEY_PASSWORD` | رمز عبور مستعار (همان رمز کلید) |

## ۵. تولید و انتشار خودکار نسخه ۱۰.۰.۰.۱ با GitHub Actions

گردش‌کار اختصاصی `.github/workflows/release-apk.yml` در پروژه فعال است. به ۳ روش ساده می‌توانید ریلیس را بسازید:

### روش ۱: استفاده از تگ گیت (پیشنهادی)
در ترمینال سیستم خود دستورات زیر را وارد کنید:
```bash
git add -A
git commit -m "آماده‌سازی نسخه رسمی ۱۰.۰.۰.۱"
git tag v10.0.0.1
git push origin main --tags
```
به محض ارسال تگ `v10.0.0.1`، ربات GitHub Actions شروع به کار کرده و ظرف ۱ الی ۲ دقیقه نسخه ۱۰.۰.۰.۱ را با فایل نصبی APK منتشر می‌کند.

### روش ۲: اجرای دستی با اسکریپت آماده
در پوشه پروژه دستور زیر را بزنید:
```bash
bash scripts/publish-to-github.sh
```

### روش ۳: اجرای دستی از طریق پنل وب گیت‌هاب
1. در صفحه مخزن گیت‌هاب به تب **Actions** بروید.
2. در ستون چپ روی گردش‌کار **Build and Release Karbama Android APK** کلیک کنید.
3. روی دکمه **Run workflow** در سمت راست بزنید، مقدار ورژن را `10.0.0.1` بگذارید و دکمه سبز را بزنید.

## ۶. فایل APK را از کجای گیت‌هاب دانلود کنیم؟ (راهنمای دانلود مستقیم)

اگر می‌خواهید فایل نصبی `karbama-v10.0.0.1.apk` را مستقیماً از گیت‌هاب دریافت کنید، مراحل زیر را طی کنید:

### گام ۱: رفتن به صفحه مخزن
وارد صفحه اصلی مخزن گیت‌هاب خود شوید:
`https://github.com/[نام_کاربری_شما]/[نام_مخزن_شما]`

### گام ۲: ورود به بخش Releases
- در صفحه اصلی مخزن، در **ستون سمت راست (سایدبار راست)** به سمت پایین اسکرول کنید.
- بخشی به نام **Releases** مشاهده می‌کنید. روی آن کلیک کنید.
- (یا می‌توانید مستقیماً آدرس زیر را در مرورگر باز کنید):
  `https://github.com/[نام_کاربری_شما]/[نام_مخزن_شما]/releases`

### گام ۳: پیدا کردن نسخه ۱۰.۰.۰.۱
در صفحه باز شده، تگ **`v10.0.0.1`** (کارباما نسخه اندروید v10.0.0.1) با برچسب **Latest** نمایش داده شده است.

### گام ۴: دانلود فایل APK
در زیر توضیحات ریلیس، بخشی به نام **Assets** وجود دارد:
1. روی آن کلیک کنید تا باز شود.
2. فایل با نام **`karbama-v10.0.0.1.apk`** را مشاهده می‌کنید.
3. با کلیک بر روی آن، دانلود فایل نصبی اندروید بلافاصله آغاز می‌شود!

### فرمت لینک مستقیم دانلود (بدون باز کردن سایت):
می‌توانید این لینک مستقیم را برای دوستان یا کارجویان بفرستید:
```text
https://github.com/[نام_کاربری_شما]/[نام_مخزن_شما]/releases/download/v10.0.0.1/karbama-v10.0.0.1.apk
```

## ۷. دانلود فوق‌سریع فایل APK از داخل خود اپلیکیشن کارباما

شما حتی نیازی به باز کردن گیت‌هاب هم ندارید! فایل نسخه ۱۰.۰.۰.۱ در خود سرور برنامه مستقر شده است:

1. وارد برنامه کارباما شوید.
2. در نوار بالای صفحه (Header) روی دکمه **«دانلود و امکانات»** ➔ **«دانلود نسخه اندروید (APK)»** کلیک کنید.
3. پنجره‌ای باز می‌شود که تب اول آن **«دانلود APK ورژن ۱۰.۰.۰.۱ (گیت‌هاب و سرور)»** است.
4. روی دکمه بزرگ سبز **«دانلود مستقیم فایل APK نسخه ۱۰.۰.۰.۱»** بزنید تا فایل مستقیماً روی گوشی یا کامپیوتر دانلود شود.
5. یا از لینک مستقیم زیر در مرورگر استفاده نمایید:
   `https://[آدرس_سایت_کارباما]/karbama-v10.0.0.1.apk`
